# Lost-response Paddle Sandbox reconciliation — review-only

When Paddle's `POST /transactions` response is lost (timeout or 5xx), the application cannot assume that no transaction was created. A durable pre-create attempt exists in the tenant-scoped journal; **do not automatically retry the POST**, rotate the intent ID, or open a second checkout for the same invoice.

The offline, dependency-free `scripts/paddle-sandbox-reconciliation-candidates.mjs` examines a *caller-supplied* listing for a potentially relevant provider transaction. It rejects missing or partial pages, duplicate transaction IDs, ambiguous intent matches, and mismatched tenant/invoice/attempt metadata, price, currency, item count, mode or status. Even with one matching candidate it returns **`review_candidate_without_persistence`**, `providerVerified:false`, `checkoutAllowed:false`, `entitlementGranted:false`, and `canRetryCreate:false`.

**Threat model:** listing flags such as `allPagesExhausted` and `filtersVerified` are untrusted caller assertions in this offline prototype, NOT proof that the Paddle Sandbox authenticated server actually returned all matching records. No remote GET is made here and no transaction is persisted. A production implementation must establish independently authenticated provider responses, verified pagination/scope, correct custom-data fields and real settled totals, and an atomic tenant-specific SQL lock before writing. The current sandbox checkout request builder only includes `epmo_intent_id` in `custom_data`, and therefore does **not** yet satisfy this classifier's additional `epmo_attempt_id`, `epmo_invoice_id`, and `epmo_tenant_id` checks. Do not wire the classifier into a live route or describe its output as Paddle proof.

Release remains blocked under issue #443: verified sandbox key and real API preflight, secure notification destination, genuine sandbox transaction, tax/invoice reconciliation, tenant isolation, and explicit launch approval. Customer checkout remains HTTP 503; no entitlement or billing activation.
