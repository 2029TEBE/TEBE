# S11 offline Saudi deployment profile gate (review only)

Run `node --test scripts/staging-region-policy.test.mjs` and `node scripts/staging-region-policy.mjs /path/to/nonsecret-profile.json`. Exit 2 rejects invalid configuration. This is an offline structural gate, **not** proof of Saudi residency, provider eligibility, deployed controls, or P0 acceptance.

Both `shared-sa` and `dedicated-sa` require explicit provider/region approval inventory, independent network/database/object storage/KMS/secrets/logging/backup/restore identifiers, HTTPS API and frontend origins, enforced TLS/WAF, encrypted backup, isolated restore, redacted logs, immutable source SHA and image digest, expand-only migration and Stripe TEST only. Dedicated profiles must declare no shared resource identifiers. Shared SaaS requires RLS enforcement. Placeholders are intentionally not deployable infrastructure.

Example input (nonsecret placeholders): `{"profile":"dedicated-sa","provider":"UNVERIFIED","region":"sa-region-pending-approval","approvedRegions":["sa-region-pending-approval"],"sourceSha":"<40 lowercase hex>","imageDigest":"sha256:<64 lowercase hex>","networkId":"<dedicated-vpc>","databaseId":"<dedicated-db>","storageId":"<dedicated-object-store>","kmsKeyId":"<dedicated-kms>","secretStoreId":"<dedicated-secret-manager>","logSinkId":"<dedicated-logs>","backupVaultId":"<encrypted-vault>","restoreTargetId":"<isolated-restore>","apiOrigin":"https://api.example.invalid/","webOrigin":"https://app.example.invalid/","tlsMode":"enforced","wafMode":"enforced","backupEncrypted":true,"logsRedacted":true,"restoreIsolated":true,"databaseMigrationMode":"expand-only","stripeMode":"test","allowLivePayments":false,"secretsInRepo":false,"usesStaticCloudKeys":false,"deploymentAuthorized":false,"sharedResourceIds":[]}`.

Cross-check before any authorized release: A01 residency/inventory and approved region; E12 API origins; F12 web origins; C09 TEST billing; real provider permissions and least privilege; independent off-host restore, deployed SHA/digest, cert/WAF/metrics/alerts, tenant RLS and rollback drill. Validator is intentionally independent of live cloud credentials and never performs deployments, DNS edits, migrations or billing.
