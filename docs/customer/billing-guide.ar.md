# THE EPMO — دليل الاشتراك والفوترة أثناء الانتقال إلى Paddle

**الحالة الحالية: عرض المعلومات فقط.** تم اختيار Paddle مزوداً للدفع، لكن إنشاء المدفوعات الجديدة وإصدار فواتير التجديد والإلغاء أو التراجع عنه غير متاح حتى اكتمال الربط والتحقق. لا ترسل بيانات البطاقة أو تحاول الدفع من خلال التطبيق في هذه المرحلة.

1. افتح صفحة **الاشتراك والفوترة** من حساب مسؤول مخوّل في مساحة العمل.
2. راجع حالة اشتراكك والخطة المسجلة والفواتير السابقة. تبقى هذه السجلات متاحة للمراجعة والمطابقة المالية.
3. الأسعار المعروضة ضمن السجلات السابقة معلومات تاريخية، ولا تمثل عرض شراء حالياً.
4. لا يمكن للتطبيق إنشاء دفعة جديدة أو تمديد الاشتراك مباشرة خلال فترة الانتقال.
5. لا تُعد أي دفعة مستقبلية عبر Paddle مؤكدة إلا بعد تحقق الخادم من التوقيع، ومطابقة العملية لنية شراء أنشأها الخادم ومساحة العمل والاشتراك، وحفظ التسوية في سجل يمنع إعادة معالجة الطلب نفسه.
6. لا تؤكد صفحة العودة أو رابط الفاتورة أو رسالة النجاح في المتصفح إتمام الدفع أو تفعيل الوصول.
7. للتجديد أو تغيير الباقة أو الإلغاء أو الاسترداد أو الاعتراض على دفعة، تواصل مع مسؤول المنصة للمراجعة قبل تنفيذ أي تغيير.

**حدود الإصدار:** لا يزال اعتماد حساب التاجر وبيانات بيئة الاختبار والأسعار وربط العمليات وإثبات التحقق من الإشعارات والتسوية المعزولة بين الجهات واختبارات التشغيل مطلوباً. لا يتم تفعيل الدفع المباشر بهذه التغييرات.
