# The EPMO — دليل الاشتراك والفوترة (الانتقال إلى Paddle)

تم اختيار **Paddle Billing** كمزوّد الدفع المستقبلي. رابط https://login.paddle.com/signup مخصّص لتسجيل حساب التاجر الخاص بالمنصة وليس صفحة دفع العملاء.

**الدفع الإلكتروني متوقف مؤقتًا.** يمكن للمسؤولين الاطلاع على سجلات الفواتير والاشتراكات السابقة. لا تستخدم صفحة الدفع القديمة عبر Stripe، ولا تعتبر العودة من صفحة الدفع إثباتًا للسداد أو لتفعيل الصلاحيات. تسجيل العملاء الجدد ما زال بطلب دعوة فقط.

بعد اعتماد حساب Paddle وإعداد المنتجات والأسعار وبيئة الاختبار، يلزم إكمال التكامل الآمن، والتحقق من توقيع `Paddle-Signature` للبيانات الخام، وربط الأحداث بالسجلات المالية وبمساحة العمل الصحيحة، واختبار الدفع والإعادة والإخفاق والإلغاء والعزل بين العملاء. تُحفظ سجلات Stripe التاريخية للمراجعة ولا تتحول تلقائيًا إلى مدفوعات Paddle.

للمساعدة في الفوترة تواصل مع مسؤول مساحة العمل أو مالك المنصة. لا ترسل بيانات البطاقات أو مفاتيح واجهة الدفع أو أسرار إشعارات الدفع عبر المحادثات أو البريد.

**حالة الإصدار: جارٍ الانتقال إلى Paddle ولم يتم اعتماد تحصيل مدفوعات العملاء بعد.**

**تنبيه:** إنشاء الفاتورة لا يجدد الاشتراك ولا يؤكد استلام الدفع.
